## README 写法约定（与 lo-pei 名下其他仓库一致）

该账号下 CEDAS、Agent Alex、案盟法规库三个仓库共用同一套 README 骨架，新仓库必须对齐：

1. `<div align="center">` 包住：`# 名称 · 中文名` → 空行 → `**一句话口号**`（短、有对仗）→
   一句话描述（用 `→` 串流程）→ shields.io 徽章行 → 锚点导航行 `[项目概览](#1-项目概览) · ...`
2. `</div>` 之后紧跟 `> **最硬的约束**：...` 引用块（一到两行）。
3. `---` 分隔，然后 **`## N. 章节名` 编号章节**，锚点即 `#N-章节名`。
4. 小节用 `### N.1`；正文大量用两列表格（`约束 | 工程实现`），表格列数必须一致。
5. 结尾 `<div align="center">**名称 · 一句收尾**</div>`。
6. 语气：精确数字 + 主动承认"未验证 / 未做"，**不要把"测量通过"写成"产品可用"**。
7. 中文引号用「」或“”，不用英文引号。

核对锚点与表格列数的小脚本思路：把 `## N. 标题` 按 GitHub slug 规则（去标点、空格转 `-`、保留中文）
生成锚点，与导航里的 `(#...)` 比对；表格按每行 `|` 计数比对。
